## Importance for Model Identification

Stationarity is a fundamental assumption in classical time series modelling.  
If the series is non-stationary, differencing is applied before estimating ARMA or ARIMA models.

The results of the stationarity test guide the appropriate order of differencing in the ARIMA framework
