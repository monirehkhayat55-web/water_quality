# water_quality
AI_ Based anomaly detection for water quality in Potomac River time series data 
This project focuses on detecting anomalies in water quality time-series data 
from the Potomac River using artificial intelligence and machine learning techniques. 
The goal is to identify abnormal patterns in environmental sensor data and support 
early warning systems for water quality monitoring.
The data  sre gathered from USGS. website  and two  stations is selected for randomly data collection resulting  make a natural  baseline for pattern recognition.
